# ADRs (Architecture Decision Records)

This directory holds short, dated records of significant architecture
decisions that aren't fully captured by `docs/SPEC.md`'s narrative form —
useful once the project has enough history that "why did we do it this way"
questions start needing a quick-reference answer.

Use the format:

```
# ADR-NNN: <short title>

Date: YYYY-MM-DD
Status: proposed | accepted | superseded by ADR-XXX

## Context
## Decision
## Consequences
```

No ADRs yet — the initial architecture is fully captured in `docs/SPEC.md`.
Start numbering at ADR-001 when the first one is needed.
